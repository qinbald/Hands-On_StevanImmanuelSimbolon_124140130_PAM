## Penjelasan repository

Repositori ini berisi bahan belajar dan latihan praktikum untuk mata kuliah Pengembangan Aplikasi Mobile. Fokus utama repositori ini adalah pembelajaran berbasis proyek dengan Kotlin Multiplatform (KMP), Compose Multiplatform, serta konsep pendukung seperti coroutines, state management, navigation, networking, storage, dan integrasi AI.

Tujuan utama repositori ini adalah menyediakan materi latihan yang bisa dikerjakan secara mandiri. Struktur folder dibuat agar mudah dipelajari per topik, dan semua materi yang bersifat pembahasan solusi disimpan secara terpisah agar mahasiswa tetap fokus pada proses pengerjaan.

## Penjelasan Singkat

- Folder `Kotlin Dasar/` berisi materi dasar pemrograman Kotlin untuk membangun fondasi sebelum masuk ke pengembangan aplikasi mobile.
- Folder `Pengembangan Aplikasi Mobile/` berisi proyek hands-on untuk materi utama matakuliah, biasanya dalam bentuk aplikasi Kotlin Multiplatform dengan modul `composeApp`.
- Setiap proyek hands-on biasanya terbagi menjadi beberapa subfolder, seperti `latihan/`, `src/`, `README.md`, dan modul pendukung lainnya.
- Folder solusi tidak ditampilkan secara terbuka pada repositori ini agar mahasiswa tetap mengerjakan tugas dari nol dan tidak langsung melihat hasil akhir.
